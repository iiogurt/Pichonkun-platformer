# Security Policy

Pichonkun is a static browser game. It has no server, no accounts and no network requests,
and only stores save data in your browser's `localStorage`. Backup files are created and read on your device; nothing is uploaded.

## Supported versions

Only the latest release, which is the version on GitHub Pages, receives fixes.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through
[GitHub security advisories](https://github.com/iiogurt/Pichonkun-platformer/security/advisories/new).
You can expect an answer within a week.
